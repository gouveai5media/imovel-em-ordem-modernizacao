# Imóvel em Ordem — Modernização do Front-end

Protótipo navegável para modernização visual do sistema legado **Imóvel em Ordem**.

## Escopo desta primeira entrega

- área do Super Admin usada por Ronaldo;
- tela “Administração de condomínios”;
- abas Vencimentos, Condomínios e Manutenções;
- busca, menus de ação e navegação responsiva;
- preservação dos textos e do fluxo funcional já existente.

Esta etapa é exclusivamente visual. Não contém banco de dados, credenciais, dados de clientes nem integração com o PHP legado.

## Abrir o protótipo

Abra `index.html` no navegador. Não há dependências, instalação ou compilação.
